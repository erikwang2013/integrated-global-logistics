## पर्यावरण आवश्यकताएँ

- PHP >= 8.3
- Composer 2.x
- MySQL >= 8.0
- Flutter >= 3.41 (केवल फ्रंटएंड विकास हेतु)
- Elasticsearch >= 7.x (वैकल्पिक, सर्च फीचर हेतु)

## त्वरित शुरुआत

### 1. निर्भरताएँ इंस्टॉल करें

```bash
composer install
```

### 2. पर्यावरण चर कॉन्फ़िगर करें

पर्यावरण चर कॉपी करके संशोधित करें (वैकल्पिक, कॉन्फ़िगर न करने पर `config/*.php` के डिफ़ॉल्ट मान उपयोग होंगे):

```bash
cp .env.example .env
```

प्रमुख कॉन्फ़िगरेशन आइटम:

| पर्यावरण चर | विवरण | डिफ़ॉल्ट मान |
|---------|------|--------|
| `JWT_SECRET` | JWT सिग्निंग कुंजी | `open-admin-jwt-secret-change-in-production` |
| `HASHIDS_SALT` | Hashids सॉल्ट मान | `open-admin-hashids-salt-2026` |
| `ENCRYPTION_KEY` | API एन्क्रिप्शन कुंजी | 32 बाइट डिफ़ॉल्ट मान |
| `SNOWFLAKE_DATACENTER_ID` | डेटासेंटर ID (0-31) | `1` |
| `SNOWFLAKE_WORKER_ID` | वर्कर नोड ID (0-31) | `1` |
| `SCOUT_HOSTS` | ES पता | `http://localhost:9200` |

**प्रोडक्शन में सभी कुंजियों को रैंडम स्ट्रिंग में बदलना अनिवार्य है।**

### 3. वन-क्लिक इंस्टॉलेशन

सेवा शुरू करने के बाद, ब्राउज़र में इंस्टॉल विज़ार्ड खोलकर डेटाबेस इनिशियलाइज़ेशन और एडमिन निर्माण पूरा करें:

```bash
php start.php start
```

डिफ़ॉल्ट रूप से `http://0.0.0.0:8787` पर लिसन करता है (पोर्ट `config/server.php` में बदला जा सकता है)।

ब्राउज़र में **`http://localhost:8787/install`** खोलें, विज़ार्ड में निम्न भरें:

| चरण | सामग्री |
|------|------|
| ① डेटाबेस कॉन्फ़िगरेशन | होस्ट पता, पोर्ट, डेटाबेस नाम, उपयोगकर्ता नाम, पासवर्ड |
| ② एडमिन सेटिंग | एडमिन उपयोगकर्ता नाम, पासवर्ड (डिफ़ॉल्ट admin / admin888) |

「इंस्टॉल शुरू करें」पर क्लिक करने पर टेबल निर्माण, अनुमति डेटा सीडिंग, एडमिन खाता निर्माण स्वचालित रूप से पूरा होता है और `.env` में डेटाबेस कॉन्फ़िगरेशन लिखा जाता है।

> इंस्टॉलेशन पूरा होने पर `runtime/install.lock` लॉक फ़ाइल बनती है। दोबारा इंस्टॉल करने के लिए इस फ़ाइल को हटाएँ।

### 4. लॉगिन

`http://localhost:8787` खोलें, इंस्टॉल के समय सेट किए गए एडमिन खाते से लॉगिन करें।

### 5. फ्रंटएंड शुरू करें (वैकल्पिक)

**Flutter एडमिन पैनल (वेब संस्करण):**

```bash
cd apps/flutter
flutter pub get
flutter run -d chrome    # वेब संस्करण (PC एडमिन पैनल शैली)
```

**HarmonyOS क्लाइंट (मोबाइल संस्करण):**

DevEco Studio से `apps/harmonyos/` डायरेक्टरी खोलें, रियल डिवाइस या एम्युलेटर से जोड़कर चलाएँ।

### 6. Docker Compose वन-क्लिक डिप्लॉयमेंट (प्रोडक्शन के लिए अनुशंसित)

प्रोजेक्ट में पूर्ण Docker ऑर्केस्ट्रेशन समाधान उपलब्ध है, जिसमें 5 सेवाएँ शामिल हैं: Nginx, PHP (webman app), MySQL, Redis, Elasticsearch।

```bash
# 1. Docker पर्यावरण चर कॉन्फ़िगर करें
cp .env.docker .env

# 2. सभी सेवाएँ शुरू करें
docker-compose up -d

# 3. ब्राउज़र में इंस्टॉल विज़ार्ड खोलकर इनिशियलाइज़ेशन पूरा करें
# http://localhost:8787/install  (डेटाबेस और एडमिन जानकारी भरें)
# या मैन्युअल रूप से SQL माइग्रेशन चलाएँ (app कंटेनर में प्रवेश करके):
# docker-compose exec app mysql -h mysql -u root -p < database/install.sql

# 4. एक्सेस
# http://localhost:8787  (webman)
# http://localhost:8080  (Nginx रिवर्स प्रॉक्सी)
```

- `Dockerfile`: PHP 8.3 + OPcache + Composer, `php:8.3-cli` पर आधारित
- `docker-compose.yml`: 5 सेवाओं का ऑर्केस्ट्रेशन, नेटवर्क आइसोलेशन, डेटा वॉल्यूम पर्सिस्टेंस
- `.env.docker`: Docker पर्यावरण के लिए विशेष पर्यावरण चर


## डेटाबेस मानक

- **टेबल प्रीफ़िक्स**: `logistics_`
- **प्राथमिक कुंजी**: सभी टेबल की प्राथमिक कुंजी `id BIGINT UNSIGNED NOT NULL` है, **AUTO_INCREMENT प्रतिबंधित**
- **ID जनरेशन**: प्राथमिक कुंजी ID ऐप्लिकेशन परत में `SnowflakeService::generate()` द्वारा जनरेट होती है, वितरित रूप से अद्वितीय
- **अनिवार्य फ़ील्ड**: हर टेबल में `id`, `created_at`, `updated_at` होना चाहिए
- **सॉफ्ट डिलीट**: सॉफ्ट डिलीट वाली टेबल में `deleted_at DATETIME DEFAULT NULL` जोड़ें
- **संवेदनशील फ़ील्ड**: फ़ोन नंबर, ईमेल, आईडी कार्ड नंबर आदि `encryptable` प्लगइन से स्वचालित एन्क्रिप्शन/डिक्रिप्शन, डेटाबेस फ़ील्ड `VARCHAR(500)` में साइफरटेक्स्ट संग्रहीत

## API दस्तावेज़

पूर्ण API संदर्भ (एकीकृत रिस्पॉन्स फॉर्मेट, एरर कोड, सभी एंडपॉइंट विवरण, प्रमाणीकरण प्रवाह, रेट लिमिट नीति, मिडलवेयर चेन) **[docs/API.hi.md](docs/API.hi.md)** में देखें, मुख्य बातें निम्न हैं:

- **एकीकृत रिस्पॉन्स फॉर्मेट**: `{ "code": 0, "message": "success", "data": {...} }`, `code=0` सफलता दर्शाता है
- **एरर कोड**: `400` पैरामीटर त्रुटि / `401` लॉगिन नहीं / `403` अनुमति नहीं / `404` मौजूद नहीं / `422` सत्यापन विफल / `429` रेट लिमिट / `500` सर्वर त्रुटि
- **API संस्करण**: रिक्वेस्ट हेडर `API-Version: v1` द्वारा नियंत्रित (अनुपस्थित होने पर डिफ़ॉल्ट v1), URL में नहीं दिखता
- **प्रमाणीकरण**: `Authorization: Bearer <token>`; access_token की वैधता 2 घंटे, refresh_token 14 दिन
- **ID हैंडलिंग**: रिक्वेस्ट/रिस्पॉन्स में ID hashids एन्क्रिप्टेड स्ट्रिंग होती है, असली डेटाबेस ID उजागर नहीं होती

## फ्रंटएंड विवरण

### Flutter एडमिन पैनल (PC शैली)

- **लेआउट**: साइडबार (64px/240px फोल्डेबल) + टॉपबार + कंटेंट एरिया, रिस्पॉन्सिव तीन ब्रेकपॉइंट (फ़ोन/टैबलेट/डेस्कटॉप)
- **पेज**: लॉगिन, डैशबोर्ड, उपयोगकर्ता प्रबंधन, भूमिका-अनुमति, सिस्टम कॉन्फ़िगरेशन, ऑपरेशन लॉग, प्रोफ़ाइल केंद्र
- **स्टेट मैनेजमेंट**: GetX (`ApiService` सिंगलटन + `AuthService` टोकन पर्सिस्टेंस)
- **डैशबोर्ड**: स्टैट कार्ड, ट्रेंड लाइन चार्ट (fl_chart), पाई चार्ट, हाल की ऑपरेशन लॉग
- **निर्यात**: Excel/PDF निर्यात, PDF में हटाने-योग्य नहीं वाली कॉपीराइट जानकारी
- **बैच ऑपरेशन**: मल्टी-सेलेक्ट बैच डिलीट, बैच सक्षम/अक्षम
- **थीम**: Material 3 लाइट/डार्क दोहरी थीम

### HarmonyOS मोबाइल संस्करण

- **पेज**: लॉगिन, डैशबोर्ड, उपयोगकर्ता सूची/विवरण, प्रोफ़ाइल केंद्र
- **प्रमाणीकरण**: JWT Bearer + 401 पर स्वचालित सीमलेस टोकन रीफ़्रेश, रीफ़्रेश विफल होने पर लॉगिन पेज पर स्वचालित रीडायरेक्ट
- **स्टोरेज**: टोकन AppStorage द्वारा प्रबंधित

## विकास मानक

- ग्लोबल फ़ंक्शन/क्लास संदर्भ में आगे `\` नहीं जोड़ें, एकीकृत रूप से `use` इम्पोर्ट करें
- सभी PHP फ़ाइलों के हेडर में कॉपीराइट घोषणा होनी चाहिए
- सभी कॉन्फ़िगरेशन फ़ाइलों में चीनी टिप्पणियाँ होनी चाहिए
- डेटाबेस प्राथमिक कुंजी ऐप्लिकेशन परत में snowflake द्वारा जनरेट होनी चाहिए, ऑटोइन्क्रीमेंट प्रतिबंधित
- API परत के सभी पैरामीटर और रिस्पॉन्स में ID hashids से एन्क्रिप्शन/डिक्रिप्शन होना चाहिए
- AdminPermission मिडलवेयर उपयोगकर्ता अनुमतियों को Redis में कैश करता है (TTL=60s), N+1 क्वेरी बाधा समाप्त करता है

## डिप्लॉयमेंट

### Docker Compose (अनुशंसित)

प्रोजेक्ट रूट में `docker-compose.yml` उपलब्ध है, जो 5 सेवाओं का ऑर्केस्ट्रेशन करता है:

| सेवा | इमेज | पोर्ट |
|------|------|------|
| `nginx` | nginx:alpine | 80, 443 |
| `app` | लोकल `Dockerfile` से बिल्ड | 8787 |
| `mysql` | mysql:8.0 | 3306 |
| `redis` | redis:7-alpine | 6379 |
| `elasticsearch` | elasticsearch:8.x | 9200 |

PHP इमेज `Dockerfile` द्वारा बिल्ड होती है, बेस इमेज `php:8.3-cli`, OPcache सक्षम।

```bash
cp .env.docker .env
docker-compose up -d
```

### CI/CD

GitHub Actions निरंतर इंटीग्रेशन पाइपलाइन: `.github/workflows/ci.yml`

- PHP सिंटैक्स जाँच (`php -l`)
- PHPUnit यूनिट टेस्ट
- Flutter स्टैटिक विश्लेषण (`flutter analyze`)

### डेटाबेस बैकअप

`database/backup/` डायरेक्टरी:

- `backup.sh` — mysqldump + gzip बैकअप, 30 दिन पुराने बैकअप स्वचालित सफाई
- `restore.sh` — इंटरैक्टिव रिस्टोर, उपलब्ध बैकअप सूचीबद्ध करके चुनने की सुविधा

### Nginx सुरक्षा कॉन्फ़िगरेशन

प्रोडक्शन डिप्लॉयमेंट में रिवर्स प्रॉक्सी सुरक्षा हार्डनिंग के लिए `docs/nginx-security.conf` देखें।
