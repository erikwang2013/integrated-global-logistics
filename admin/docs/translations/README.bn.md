## এনভায়রনমেন্ট প্রয়োজনীয়তা

- PHP >= 8.3
- Composer 2.x
- MySQL >= 8.0
- Flutter >= 3.41 (শুধুমাত্র ফ্রন্টএন্ড ডেভেলপমেন্টের জন্য প্রয়োজন)
- Elasticsearch >= 7.x (ঐচ্ছিক, সার্চ ফিচারের জন্য প্রয়োজন)

## দ্রুত শুরু

### 1. ডিপেন্ডেন্সি ইনস্টল

```bash
composer install
```

### 2. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার

এনভায়রনমেন্ট ভেরিয়েবল কপি ও পরিবর্তন করুন (ঐচ্ছিক, কনফিগার না করলে `config/*.php`-এর ডিফল্ট মান ব্যবহার হয়):

```bash
cp .env.example .env
```

মূল কনফিগারেশন আইটেম:

| এনভায়রনমেন্ট ভেরিয়েবল | বর্ণনা | ডিফল্ট মান |
|---------|------|--------|
| `JWT_SECRET` | JWT সিগনেচার কী | `open-admin-jwt-secret-change-in-production` |
| `HASHIDS_SALT` | Hashids সল্ট | `open-admin-hashids-salt-2026` |
| `ENCRYPTION_KEY` | API এনক্রিপশন কী | ৩২ বাইট ডিফল্ট মান |
| `SNOWFLAKE_DATACENTER_ID` | ডেটাসেন্টার ID (0-31) | `1` |
| `SNOWFLAKE_WORKER_ID` | ওয়ার্কার নোড ID (0-31) | `1` |
| `SCOUT_HOSTS` | ES ঠিকানা | `http://localhost:9200` |

**প্রোডাকশন পরিবেশে অবশ্যই সব সিক্রেট কী র্যান্ডম স্ট্রিং দিয়ে বদলাতে হবে।**

### 3. ওয়ান-ক্লিক ইনস্টল

সার্ভিস চালু করার পর ব্রাউজার দিয়ে ইনস্টলেশন উইজার্ডে গিয়ে ডেটাবেস ইনিশিয়ালাইজেশন ও অ্যাডমিন তৈরি সম্পন্ন করুন:

```bash
php start.php start
```

ডিফল্টভাবে `http://0.0.0.0:8787` পোর্টে শোনে (পোর্ট `config/server.php`-এ পরিবর্তন করা যায়)।

ব্রাউজারে **`http://localhost:8787/install`** খুলে উইজার্ড অনুযায়ী পূরণ করুন:

| ধাপ | বিষয়বস্তু |
|------|------|
| ① ডেটাবেস কনফিগারেশন | হোস্ট ঠিকানা, পোর্ট, ডেটাবেস নাম, ইউজারনেম, পাসওয়ার্ড |
| ② অ্যাডমিন সেটআপ | অ্যাডমিন ইউজারনেম, পাসওয়ার্ড (ডিফল্ট admin / admin888) |

「ইনস্টল শুরু করুন」 ক্লিক করলে স্বয়ংক্রিয়ভাবে টেবিল তৈরি, পারমিশন সিড ডেটা, অ্যাডমিন অ্যাকাউন্ট তৈরি হবে এবং `.env`-এ ডেটাবেস কনফিগারেশন লেখা হবে।

> ইনস্টল শেষে `runtime/install.lock` লক ফাইল তৈরি হয়। পুনরায় ইনস্টল করতে চাইলে এই ফাইলটি ডিলিট করুন।

### 4. লগইন

`http://localhost:8787` অ্যাক্সেস করে ইনস্টলের সময় সেট করা অ্যাডমিন অ্যাকাউন্ট ও পাসওয়ার্ড দিয়ে লগইন করুন।

### 5. ফ্রন্টএন্ড চালু করুন (ঐচ্ছিক)

**Flutter অ্যাডমিন ব্যাকএন্ড (ওয়েব):**

```bash
cd apps/flutter
flutter pub get
flutter run -d chrome    # ওয়েব সংস্করণ (PC অ্যাডমিন ব্যাকএন্ড স্টাইল)
```

**HarmonyOS ক্লায়েন্ট (মোবাইল):**

DevEco Studio দিয়ে `apps/harmonyos/` ডিরেক্টরি খুলে রিয়েল ডিভাইস বা ইমুলেটরে চালান।

### 6. Docker Compose ওয়ান-ক্লিক ডিপ্লয় (প্রোডাকশন পরিবেশে প্রস্তাবিত)

প্রজেক্টে সম্পূর্ণ Docker অর্কেস্ট্রেশন সমাধান দেওয়া আছে, ৫টি সার্ভিসসহ: Nginx, PHP (webman app), MySQL, Redis, Elasticsearch।

```bash
# 1. Docker এনভায়রনমেন্ট ভেরিয়েবল কনফিগার
cp .env.docker .env

# 2. সব সার্ভিস চালু করুন
```

## ডেটাবেস নিয়মাবলি

- **টেবিল প্রিফিক্স**: `logistics_`
- **প্রাইমারি কী**: সব টেবিলের প্রাইমারি কী `id BIGINT UNSIGNED NOT NULL`, **AUTO_INCREMENT নিষিদ্ধ**
- **ID জেনারেশন**: প্রাইমারি কী ID অ্যাপ্লিকেশন লেয়ারে `SnowflakeService::generate()` দিয়ে তৈরি, ডিস্ট্রিবিউটেড-ইউনিক
- **বাধ্যতামূলক ফিল্ড**: প্রতিটি টেবিলে `id`, `created_at`, `updated_at` থাকতে হবে
- **সফট ডিলিট**: সফট ডিলিট প্রয়োজন এমন টেবিলে `deleted_at DATETIME DEFAULT NULL` যোগ করুন
- **সংবেদনশীল ফিল্ড**: ফোন নম্বর, ইমেইল, আইডি কার্ড নম্বর ইত্যাদি `encryptable` প্লাগইন দিয়ে অটো এনক্রিপ্ট/ডিক্রিপ্ট হয়, ডেটাবেস ফিল্ডে `VARCHAR(500)` দিয়ে সাইফারটেক্সট সংরক্ষিত হয়

## API ডকুমেন্টেশন

সম্পূর্ণ API রেফারেন্স (ইউনিফাইড রেসপন্স ফরম্যাট, এরর কোড, সব এন্ডপয়েন্টের বিস্তারিত, অথেনটিকেশন ফ্লো, রেট লিমিট পলিসি, মিডলওয়্যার চেইন) **[docs/API.bn.md](docs/API.bn.md)**-তে দেখুন, মূল পয়েন্টগুলো:

- **ইউনিফাইড রেসপন্স ফরম্যাট**: `{ "code": 0, "message": "success", "data": {...} }`, `code=0` মানে সফল
- **এরর কোড**: `400` প্যারামিটার এরর / `401` লগইন নেই / `403` অনুমতি নেই / `404` নেই / `422` ভ্যালিডেশন ব্যর্থ / `429` রেট লিমিট / `500` সার্ভার এরর
- **API ভার্সন**: রিকোয়েস্ট হেডার `API-Version: v1` দিয়ে নিয়ন্ত্রিত (না দিলে ডিফল্ট v1), URL-এ প্রকাশিত হয় না
- **অথেনটিকেশন**: `Authorization: Bearer <token>`; access_token ২ ঘণ্টা, refresh_token ১৪ দিন বৈধ
- **ID হ্যান্ডলিং**: রিকোয়েস্ট/রেসপন্সের ID hashids এনক্রিপ্টেড স্ট্রিং, আসল ডেটাবেস ID প্রকাশ পায় না

## ডিপ্লয়

### Docker Compose (প্রস্তাবিত)

প্রজেক্ট রুটে `docker-compose.yml` দেওয়া আছে, ৫টি সার্ভিস অর্কেস্ট্রেট করে:

| সার্ভিস | ইমেজ | পোর্ট |
|------|------|------|
| `nginx` | nginx:alpine | 80, 443 |
| `app` | লোকাল `Dockerfile` দিয়ে বিল্ড | 8787 |
| `mysql` | mysql:8.0 | 3306 |
| `redis` | redis:7-alpine | 6379 |
| `elasticsearch` | elasticsearch:8.x | 9200 |

PHP ইমেজ `Dockerfile` দিয়ে বিল্ড হয়, বেস ইমেজ `php:8.3-cli`, OPcache সক্রিয়।

```bash
cp .env.docker .env
docker-compose up -d
```

### CI/CD

GitHub Actions কন্টিনিউয়াস ইন্টিগ্রেশন পাইপলাইন: `.github/workflows/ci.yml`

- PHP সিনট্যাক্স চেক (`php -l`)
- PHPUnit ইউনিট টেস্ট
- Flutter স্ট্যাটিক অ্যানালাইসিস (`flutter analyze`)

### ডেটাবেস ব্যাকআপ

`database/backup/` ডিরেক্টরি:

- `backup.sh` — mysqldump + gzip ব্যাকআপ, ৩০ দিন আগের পুরনো ব্যাকআপ স্বয়ংক্রিয় পরিষ্কার
- `restore.sh` — ইন্টারঅ্যাকটিভ রিস্টোর, উপলব্ধ ব্যাকআপ তালিকা দেখিয়ে নির্বাচন

### Nginx নিরাপত্তা কনফিগারেশন

প্রোডাকশন ডিপ্লয়ে `docs/nginx-security.conf` দেখে রিভার্স প্রক্সি নিরাপত্তা হার্ডেনিং কনফিগার করুন।
