Full-stack admin dashboard based on webman v2 + Flutter.

## Feature List

| Domain | Feature |
|----|------|
| Authentication | Login/Register/Refresh/Logout + CAPTCHA + account lockout + session limit |
| Dashboard | Real-time stats/trends/distribution/logs (Redis 5m cache) |
| Users | CRUD + batch delete/enable-disable + Excel import |
| Roles & Permissions | CRUD + permission tree + RBAC method.path authorization |
| System Config | Key-value CRUD |
| Operation Audit | Log query + automatic detection of 8 platform client sources |
| Files | Upload + Excel/PDF export (sensitive data masking) |
| Security | 18-layer defense in depth (XSS/SQL injection/CSRF/rate limiting/CSP...) |
| Operations | Health check/Prometheus metrics/API docs/security.txt + Docker + CI/CD |

## Tech Stack

### Backend
- PHP 8.3+, webman v2 (workerman/webman)
- Database: MySQL 8.0+, table prefix `logistics_`
- Primary key: BIGINT, non-auto-increment, generated by `erikwang2013/snowflake-php`
- API-layer ID encryption/decryption: `erikwang2013/hashids`
- JWT authentication: `erikwang2013/jwt-webman`
- API sensitive data encryption/decryption: `erikwang2013/encryption`
- DB sensitive field encryption/decryption: `erikwang2013/encryptable`
- ES sync and query: `erikwang2013/webman-scout`
- Country flags: `erikwang2013/season`

### Frontend
- Flutter 3.x, source directory `apps/flutter/`
- Web end designed in PC admin-panel style (not mobile App style)
- Supports client and admin ends
- HarmonyOS ArkTS, source directory `apps/harmonyos/`

## Middleware Execution Chain

```
全局:  Cors → Locale(Accept-Language) → SecurityFilter(方法检查→405) → RateLimit → {路由中间件}
/admin: Cors → Locale(Accept-Language) → SecurityFilter(方法检查→405) → RateLimit → AdminAuth → AdminPermission → OperationLog → Controller
/api:   Cors → Locale(Accept-Language) → SecurityFilter(方法检查→405) → RateLimit → ApiVersion → Controller
/health: Cors → Locale(Accept-Language) → SecurityFilter(方法检查→405) → RateLimit → Controller
```

## Security Enhancements

- **HTTP method restriction**: SecurityFilter only allows GET/POST/PUT/DELETE/OPTIONS/HEAD; non-standard methods return 405
- **CSP header**: Content-Security-Policy + X-Permitted-Cross-Domain-Policies injected into all responses
- **Account lockout**: after 5 consecutive failed logins, the account is locked for 15 minutes
- **Concurrent session limit**: at most 3 valid tokens per user; the oldest token is blacklisted when exceeded
- **security.txt**: `/.well-known/security.txt` RFC 9116 endpoint
- **Nginx security config**: `docs/nginx-security.conf` reverse-proxy hardening reference

## API Versioning Policy

The version is controlled via the `API-Version` request header (default `v1`), not reflected in the URL:

```bash
curl -H "API-Version: v1" http://localhost:8787/api/auth/login
```

Adding a new version only requires creating the `app/api/{version}/controller/` directory and registering it in the `ApiVersion` middleware.

## Rate Limiting Policy

Redis sliding window (Lua atomic), default 60 req/min/IP/route:
- Login: 10 req/min
- Register: 5 req/min
- Response headers: `X-RateLimit-Limit/Remaining/Reset`, plus `Retry-After` when exceeded

## Code Standards

### PHP
- Global functions/class references are not prefixed with `\`; import them with `use`
- Config files must include Chinese comments explaining the meaning of each config item
- All new `.php` files must include the copyright notice in the file header
- **Redis is accessed via the `support\Redis` utility class** (singleton connection pool, automatically reads the `REDIS_HOST/PORT/PASSWORD/DB` environment variables); all keys are automatically prefixed (default `open-admin:`, configurable via the `REDIS_PREFIX` environment variable)
- **Route permissions**: routes in the `/admin` group require `method.path`-style permissions (e.g. `get.admin/dashboard`); routes needing no permission check are placed outside the group with only the `AdminAuth` middleware
- **CORS**: when adding request headers, update the `Cors.php` middleware and the `Access-Control-Allow-Headers` fallback in `route.php` accordingly
- **Super admin protection**: the `update`/`destroy` methods of `RoleController` are forbidden from operating on roles with `slug == 'super_admin'`
- webman converts PHP warnings into exceptions; undefined properties/variables cause 500 errors

### Database
- Table prefix: `logistics_`
- Primary key `id`: BIGINT type, non-auto-increment, generated by snowflake
- Sensitive fields use the `erikwang2013/encryptable` trait for automatic encryption/decryption
- Migration files use SQL format

### Flutter
- Web layout uses PC admin-panel style (sidebar + top bar + content area)
- GetX state management; **all API requests must go through the `ApiService` singleton** (Dio + JWT interceptor); creating standalone Dio instances or hardcoding baseUrl is forbidden
- Token persistence uses `shared_preferences`
- Responsive breakpoints: mobile (< 768px) and desktop (>= 768px)
- **Page header Rows must use `Wrap`** to prevent overflow when the sidebar expands; filter ChoiceChips must be wrapped in `Obx` for reactive updates
- **DataTables must be wrapped in `SingleChildScrollView(scrollDirection: Axis.horizontal)`** to prevent column overflow
- Standalone pages (e.g. ProfilePage) must include a `Scaffold`, otherwise Material widgets like `TextField` throw "No Material widget found"
- When the sidebar expands/collapses, use `_showCollapsedContent` to delay content switching, avoiding RenderFlex overflow during animation

### HarmonyOS
- Uses the `@ohos.net.http` native HTTP client
- Seamless token refresh: auto-calls `/api/auth/refresh` on 401
- Auto-redirects to the login page when refresh fails

## Deployment

### Docker Compose (recommended for production)

The `docker-compose.yml` at the project root orchestrates 5 services:

| Service | Description |
|------|------|
| `nginx` | Nginx reverse proxy (80/443), static file serving |
| `app` | webman PHP 8.3 application, built via `Dockerfile` (with OPcache) |
| `mysql` | MySQL 8.0, persistent data volume |
| `redis` | Redis 7 Alpine, cache/rate limiting/Session |
| `elasticsearch` | Elasticsearch 8.x, full-text search |

```bash
cp .env.docker .env
docker-compose up -d
```

### CI/CD

`.github/workflows/ci.yml` defines the GitHub Actions pipeline:

- PHP syntax check (`php -l`)
- PHPUnit unit tests
- Flutter static analysis (`flutter analyze`)

### Database Backup

`database/backup/backup.sh` — mysqldump + gzip, auto-cleans backups older than 30 days.
`database/backup/restore.sh` — interactive restore, lists available backups for selection.

### Monitoring

The `GET /metrics` endpoint (`MetricsController`) outputs Prometheus text format with 5 gauge metrics:
- `openadmin_http_requests_total` — total requests
- `openadmin_active_users` — active users
- `openadmin_db_connection_status` — database connection status (0/1)
- `openadmin_redis_connection_status` — Redis connection status (0/1)
- `openadmin_memory_usage_bytes` — memory usage
